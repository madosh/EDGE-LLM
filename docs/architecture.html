Google LiteRT

Edge-optimized inference with NPU/GPU acceleration
APIGemini-compatible REST (/v1beta/models/:generateContent)
Served bylit serve --model gemma3-1b --port 8000
Metricstps and TTFT from usageMetadata token counts
Env varsLITERT_URL, LITERT_MODEL
Best forMobile, RPi, Jetson, MediaTek, Qualcomm NPU devices

Ollama

Local LLM server with broad model support
APIOllama REST (/api/generate, /api/pull, /api/ps)
Served byollama serve (port 11434)
Metricstps from eval_count/eval_duration, TTFT from prompt_eval_duration, memory from /api/ps
Env varsOLLAMA_URL
Best forx86/ARM servers with CUDA or CPU inference

Stub Mode

Synthetic metrics with no external runtime
APINone (internal random number generation)
Served byBuilt-in, no process needed
Metricstps ~28 +/- 3, TTFT ~120 +/- 20 ms, mem ~3800 MB
Env varsDefault when no URL is configured
Best forCI pipelines, demos, development without GPU

Device States

stateDiagram-v2 [*] --> registering : Agent starts\nRegister() RPC registering --> online : Registration OK\nHeartbeat begins online --> online : Heartbeat received\n(every ~10 s) online --> offline : No heartbeat\nfor ~30 s\n(watchdog job) offline --> online : Agent re-registers\nor new heartbeat offline --> [*] : Container removed

Deployment States

stateDiagram-v2 [*] --> pending : POST /api/deployments pending --> downloading : DeploymentInstruction\ndelivered via gRPC stream downloading --> verifying : Tarball fully received\nsha256 check begins verifying --> running : Hash matches\nBackend loads model verifying --> failed : Hash mismatch\nRefused to load downloading --> failed : Network error /\nHTTP non-200 running --> [*] : Device goes offline\nor deployment replaced

P1 - Core Feature Gaps

Agent retry logic - No backoff on registration failure. Watch stream break kills deployment reception. No tokio::signal for graceful shutdown.
REST validation - POST /api/deployments accepts empty model_id, invalid SHA-256, and empty tag selectors.
Web UI fixes - Artifact dropdown resets on polling refresh. No loading/empty/error skeleton states on device detail.
Telemetry charts - SVG sparklines are functional but basic. Could use a chart library for zoom, tooltips, time range selection.

P2/P3 - Hardening & Polish

NATS subscribers - Event bus is wired but publish-only. No consumers anywhere.
Pagination - GET /api/devices and /api/deployments return all rows with no limit/offset.
Per-device certs - v0 uses a shared device.crt for all agents. Production needs per-device identity.
CORS - Access-Control-Allow-Origin: * in REST server. Restrict to known origins.
TypeScript - API client uses generic get<T> but callers pass any. Needs exported interfaces.
